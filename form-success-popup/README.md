# Попап успеха формы для Tilda Zero Block

Подмена стандартного окна успешной отправки на зеро-блок попапа. Стили: центр экрана, фон `#DDE3EB` 60% + blur 60px, блок скролла, закрытие по клику на фон.

## Подключение

1. На странице должен стоять виджет Nolim «показать зеро-блок после успеха» — из его settings сниппет сам берёт ID формы, ID попапа и ссылку закрытия.
2. Весь файл `form-success-popup/tilda-embed.html` вставить в HTML-элемент Тильды (T123). ID блоков в сниппете прописывать не нужно.

Кнопки закрытия в зеро-блоке попапа — как в Nolim (`#closeallpopup` по умолчанию).

## Поведение

- Фон оверлея: `#DDE3EB` с прозрачностью 60% и `backdrop-filter: blur(60px)`.
- Карточка всегда по центру экрана на всех вьюпортах и после повторной отправки.
- Пока попап открыт, скролл страницы заблокирован.
- Клик по фону закрывает попап; форма снова доступна для отправки.
- Закрытый попап не перехватывает тапы — на мобилке кнопка отправки остаётся кликабельной.

## Демо

`form-success-popup/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
