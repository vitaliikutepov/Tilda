# Попап успеха формы для Tilda Zero Block

Подмена стандартного окна успешной отправки на зеро-блок попапа. Для страницы [secure-applications-ai-era](https://positech.id/webinars/secure-applications-ai-era).

## Подключение

1. Зеро-блок попапа — `#rec3331835203`  
   карточка — группа `data-group-id="1775812703037000001"`, кнопки закрытия ведут на `#closeallpopup`.
2. Зеро-блок с формой — `#rec3315174201`.
3. Виджет Nolim «показать зеро-блок после успеха» можно оставить: сниппет перехватывает показ и чинит стили. Если Nolim нет — сам слушает `tildaform:aftersuccess`.
4. Весь файл `form-success-popup/tilda-embed.html` вставить в HTML-элемент Тильды (T123).

ID блоков и группы карточки меняются в константах в начале `<script>`.

## Поведение

- Фон оверлея: `#DDE3EB` с прозрачностью 60% и `backdrop-filter: blur(60px)`.
- Карточка всегда по центру экрана на всех вьюпортах и после повторной отправки.
- Пока попап открыт, скролл страницы заблокирован.
- Клик по фону (и кнопки `#closeallpopup`) закрывает попап; форма снова доступна для отправки.

## Демо

`form-success-popup/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
