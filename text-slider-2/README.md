# Текстовый слайдер 2 для Tilda Zero Block

Отдельная версия слайдера с автопроигрыванием и пагинацией «прогрессбар + точки» для страницы [h1bg-special](https://form.ptsecurity.com/h1bg-special) (зеро-блок `#rec3367388301`). Первый слайдер (`text-slider/`, `#rec3351087301`) не трогает.

## Подключение

1. В зеро-блоке UI:
   - стрелки `.main-slider-left-2` / `.main-slider-right-2`;
   - текстовый элемент `.slider-text-3`;
   - группа `.text-slider-2`;
   - пагинация: группы `.cslide4-1` … `.cslide4-4` и шейпы `.slide4-1` … `.slide4-4`.
     В макете 4 пункта; пятый скрипт клонирует. Активный пункт — полоска 24×4, остальные — точки 4×4.
2. Весь файл `text-slider-2/tilda-embed.html` вставить в HTML-элемент Тильды (отдельно от первого слайдера).
3. Тексты слайдов — массив `SLIDE_TEXTS` внутри сниппета:
   1. Ведущий разработчик продуктов, решений и сервисов для выявления и предотвращения кибератак до того, как они причинят неприемлемый ущерб бизнесу
   2. Специалисты Positive Technologies участвуют в разработке требований информационной безопасности в составе рабочих групп ФСТЭК России, Банка России и других регуляторов
   3. Positive Technologies — один из лидеров в области результативной кибербезопасности
   4. Чтобы продемонстрировать эффективность результативного подхода к кибербезопасности, компания проводит киберучения на собственной инфраструктуре и публично тестирует свои продукты
   5. Первая и пока единственная компания из сферы кибербезопасности на Московской бирже (MOEX: POSI). Количество акционеров превышает 220 тысяч

## Поведение

- Текст fill + autoheight (как в макете Тильды): фейд 0.5с, без hug. На всех брейкпоинтах строка переносится, потолок ширины: &lt;768 — 280px, 768–1024 — 616px, 1024–1366 — 1002px, 1366+ — 864px.
- Высота текстового блока едет 0.5с (`cubic-bezier(.25,.1,.25,1)`). Пагинация в потоке колонки (Тильда держит её с абсолютным `top` 110/80/140/136px) — точки скользят вверх/вниз вместе с числом строк, а не прыгают.
- Автосмена каждые 5 секунд; прогресс плавно заполняет активный пункт (серый трек `#676767`, белая заливка через `scaleX`). Активный пункт сразу 24px.
- Пять пунктов пагинации: активный — прогрессбар, остальные — белые точки.
- Клик по стрелке / точке или свайп сбрасывают таймер.
- Наведение на блок ставит автоплей на паузу.
- Селекторы ограничены `#rec3367388301`, чтобы не задеть первый слайдер.
