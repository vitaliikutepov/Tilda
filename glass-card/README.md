# Стеклянные карточки `.glass-card`

CSS для зеро-блока Тильды: полупрозрачный белый фон, тонкая обводка и сильный blur. Скругления не задаются — остаются те, что выставлены в редакторе.

## Подключение

1. На фигуре или группе в зеро-блоке укажите CSS-класс `glass-card`.
2. Вставьте `tilda-embed.html` в HTML-элемент Тильды (или в HTML-код страницы).

## Стили

| Свойство | Значение |
| --- | --- |
| Фон | `#FFFFFF` 20% (`rgba(255, 255, 255, 0.2)`) |
| Обводка | `1px` `#FFFFFF` 20% |
| Blur | `120px` (`backdrop-filter`) |
| Скругление | как в Тильде |

Класс вешается на элемент/группу; заливка в Zero Block живёт на `.tn-atom` / `.tn-molecule` — сниппет красит именно их.

## Демо

`glass-card/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
