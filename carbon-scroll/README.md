# SVG-анимация по скроллу (Carbon)

Пять этапов с макета: пунктирные потоки → гексагональная сетка → три маршрута атаки → карточки → кольцевые шкалы.

## Вставка в Тильду

1. HTML-блок **T123**, ширина 100%, отступы 0, фон прозрачный.
2. Вставить целиком `tilda-embed.html`.
3. Кадр чёрный, высота 100vh, липнет к экрану. Сам блок ~9 экранов — этого хватает, чтобы проскроллить весь сюжет.

Адаптив пока не заложен.

## Сюжет

1. Из пустоты сверху вниз открываются пунктирные линии; по ним стекают точки и схлопываются в ноль. На паузе точки продолжают идти.
2. Точки гаснут, линии растворяются, сетка гексагонов прорисовывается сверху вниз и на паузе медленно пульсирует.
3. Три маршрута атаки распускаются из своих центров, появляются подписи.
4. Сетка уходит в фейд, маршруты едут на места трёх равных карточек, в углах проявляются подписи. По карточкам бежит блик.
5. Карточки гаснут. Слева направо появляются тёмные круги, серебряная шкала заполняется, цифры пересчитываются.

После сборки `tilda-embed.html` из исходников:

```
python3 carbon-scroll/build.py
```

Исходные SVG лежат в `src/1.svg`…`5.svg`.
