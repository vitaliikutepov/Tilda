# Ограничение высоты зеро-блока

Сниппет для блока `#rec3351087101`. Код для вставки: `artboard-max-height/tilda-embed.html`.

## Поведение

- **1366–1919px** — высота `100vh`, максимум **1080px**
- **1920px и шире** — высота `100vh`, максимум **1220px**
- **ниже 1366px** — скрипт ничего не делает

Патч перехватывает `t396_ab__getHeight`, чтобы Тильда считала масштаб блока от урезанной высоты.

## Демо

`artboard-max-height/demo.html` — открывать через локальный сервер. Можно задать ширину через `?w=1920`.
