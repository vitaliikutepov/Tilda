# Моргание точек SVG для Tilda Zero Block

Анимация точек из макета (например [Group_2136139868.svg](https://static.tildacdn.com/tild6562-3964-4135-b062-323031376465/Group_2136139868.svg)): цвет (`fill`) остаётся как в SVG, меняется только прозрачность. Часть точек медленно дышит, часть коротко вспыхивает.

## Подключение

1. В зеро-блоке элементу с SVG задайте класс `svg-dots`.
2. Весь файл `tilda-embed.html` вставьте в HTML-элемент Тильды.

Скрипт работает и с картинкой (`<img src="…svg">`), и с уже вставленным инлайновым `<svg>`. Для `<img>` файл скачивается и подменяется инлайном — иначе CSS не может анимировать отдельные точки.

## Поведение

- `fill` не перекрашивается.
- Групповая прозрачность из Figma (например `opacity="0.1"`) переносится на точки как базовый уровень.
- Часть точек медленно почти гаснет (opacity близко к 0), часть чуть ярче, часть коротко моргает.
- Около трети точек остаются статичными.
- Остальные получают случайную длительность (примерно 3–7 с) и задержку.
- При `prefers-reduced-motion` анимация отключается.

## Демо

`demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
