# Неактивные аккордеоны направлений

Сниппет для страницы [Fast Track](https://pt-start.ptsecurity.com/fast-track): закрытые направления нельзя раскрыть, поверх карточки — затемнение и стикер «набор закрыт».

## Подключение

1. Откройте `accordion-inactive/tilda-embed.html` и в начале скрипта заполните `INACTIVE_IDS` — id шапок аккордеона через запятую:

```js
var INACTIVE_IDS = 'rec3084349501, rec2915718001';
```

Классы в Тильде задавать не нужно: скрипт ищет карточку и кнопки плюс/минус внутри указанных блоков.

Примеры id на `/fast-track`:

| Блок | Направление |
| --- | --- |
| `rec2914914801` | Разработка Python |
| `rec2915718001` | Тестирование QA |
| `rec3084349501` | Кибербезопасность |

2. Вставьте весь файл в HTML-элемент Тильды (настройки страницы или HTML-блок ниже аккордеонов).

## Поведение

- Карточка перекрывается дивом `#212228` с прозрачностью 50%. Высота следует за блоком, клик не проходит — аккордеон не раскрывается.
- Кнопки плюс/минус скрыты через `opacity: 0`. Слой поверх карточки блокирует клики и ховер; цвет фона аккордеона не меняется.
- Стикер всегда **250px** по ширине.
- До 768px стикер по центру в полосе 80px; низ клипится обёрткой `.pts-acc-round` (скругление 12px). Spacer 92px, чтобы зазор между блоками был под радиусом, а не поверх него.
- От 768px десктопный стикер справа и на 10px выходит за правый край.
