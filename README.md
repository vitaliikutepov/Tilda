# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `artboard-max-height/` — ограничение высоты `#rec3351087101`: 1080px на 1366–1919 и 1220px от 1920. Код для вставки: `artboard-max-height/tilda-embed.html`.
