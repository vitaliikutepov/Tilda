# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `overlap-cards/` — стек из 4 карточек с нахлёстом, по ховеру выдвигается описание. В Тильду вставлять только `overlap-cards/tilda-embed.html` (не `demo.html`).
