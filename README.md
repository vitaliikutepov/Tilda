# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `form-success-popup/` — попап успеха формы (центр экрана, фон `#DDE3EB` 60% + blur 60px, блок скролла, закрытие по клику на фон). Код для вставки: `form-success-popup/tilda-embed.html`.
