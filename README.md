# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `tilda-fixed-banner/` — стики-баннер внизу экрана (`#rec2643778101`). На мобилке раскрывается тапом по карточке. Код для вставки: `tilda-fixed-banner/tilda-embed.html`.
