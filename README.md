# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `text-slider/` — текстовый слайдер (`.slider-text-2`, `.cslide4-1`…`.cslide4-4`, автосмена 5с, прогрессбар + точки). Код для вставки: `text-slider/tilda-embed.html`.
