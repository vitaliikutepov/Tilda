# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `glass-card/` — стеклянные карточки (`.glass-card`: фон `#FFFFFF` 20%, обводка 1px, blur 120px; скругления из Тильды). Код для вставки: `glass-card/tilda-embed.html`.
