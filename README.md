# Tilda

## Panorama Slider для Zero Block

Бесконечная зацикленная карусель фотографий (2:3) с эффектом «панорамы»:
крайние карточки плавно разворачиваются и уходят вглубь, лента медленно
и непрерывно движется слева направо. Без элементов управления — только
автопроигрывание.

### Файлы

- `panorama-slider.html` — код для вставки в Тильду (стили + скрипт).
- `demo.html` — автономная демо-страница для локального просмотра
  (можно просто открыть в браузере двойным кликом).

### Как встроить в Zero Block

1. В Zero Block добавьте элемент **Shape** (фрейм) нужного размера —
   это будет область слайдера. В настройках элемента
   (**Settings → CSS Class Name**) укажите класс `panorama`.
2. Добавьте в тот же Zero Block элемент **HTML** и вставьте в него
   весь код из файла `panorama-slider.html`.
3. В массиве `IMAGES` в начале скрипта замените ссылки на свои
   10 фотографий (вертикальные, соотношение сторон 2:3), например:
   `https://static.tildacdn.com/tild3432-3430-4661-b861-633639383164/samuelzeller168234.jpg`

Карусель сама заполнит фрейм и выровняется по его вертикальному центру.

### Настройки

В начале скрипта можно менять параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `SPEED` | `30` | скорость движения, px в секунду |
| `MAX_ANGLE` | `45` | угол разворота крайних карточек, градусы |
| `DEPTH` | `240` | насколько края выступают вперёд, px |
| `GAP` | `14` | расстояние между карточками, px |
| `CARD_HEIGHT` | `0.46` | высота карточки относительно высоты фрейма |
| `RATIO` | `2/3` | соотношение сторон фотографий |
