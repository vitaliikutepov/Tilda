# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `text-slider/` — текстовый слайдер 1 (`.slider-text-2`, `.cslide4-1`…`.cslide4-4`, автосмена 5с, прогрессбар + точки). Блок `#rec3351087301`. Код: `text-slider/tilda-embed.html`.
- `text-slider-2/` — текстовый слайдер 2 (`.slider-text-3`, `.main-slider-left-2` / `.main-slider-right-2`, 5 слайдов). Блок `#rec3367388301`. Код: `text-slider-2/tilda-embed.html`.
