# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `scroll-section/` — скролл-анимация `.scroll-section`: на 1024px+ сначала на всю ширину окна, при доскролле сужается к размерам из Тильды. Код для вставки: `scroll-section/tilda-embed.html`.
