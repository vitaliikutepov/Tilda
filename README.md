# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `menu-icon-tooltips/` — тултипы иконок в шапке по hover (фикс Windows, где Тильда показывает подписи сразу). Код: `menu-icon-tooltips/tilda-embed.html`.
