# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `mobile-scroll-paint/` — на мобилке зеро-блоки не ждут appear-анимацию (пустой серый фон при скролле). Код: `mobile-scroll-paint/tilda-embed.html`.
