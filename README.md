# Tilda

Сниппеты для зеро-блоков Тильды.

- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `svg-scroll-story/` — SVG-анимация по скроллу, три этапа с переходами по ролям. Разбор consider.digital/story и прототип: `svg-scroll-story/demo.html`.
- `carbon-scroll/` — пятиэтапная SVG-анимация (потоки → сетка → маршруты → карточки → шкалы) для T123: `carbon-scroll/tilda-embed.html`.
