- `tab-slider/` — таб-слайдер (`.tab-container`, `.tab1`…`.tab6`, автосмена 6с). Код для вставки: `tab-slider/tilda-embed.html`.
- `overlap-cards/` — стек warning-карточек в `#rec3354439901` (h1bg-special): ховер ≥1366, аккордеон ниже. В Тильду: `overlap-cards/tilda-embed.html`.
