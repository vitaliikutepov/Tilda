# Стек warning-карточек (`#rec3354439901`)

Сниппет для зеро-блока на [h1bg-special](https://form.ptsecurity.com/h1bg-special). Берёт уже свёрстанные группы `.warningcard-1` … `.warningcard-4`, оборачивает их во flex-стек и включает раскрытие.

## Что вставлять

Только **`overlap-cards/tilda-embed.html`** — в HTML-элемент страницы или T123. Не `demo.html`.

В редакторе Тильда HTML не рисует — нужна публикация.

## Поведение

- Стек с автолейаутом: открытие верхней карточки сдвигает нижние вниз.
- Экраны **≥1366px** — раскрытие по ховеру.
- Экраны **&lt;1366px** — аккордеон по тапу, одна открытая карточка.
- Стиль карточки: фон `#FF0000` 10%, обводка 1px `#FF0000` 10%, `backdrop-filter: blur(150px)`, радиус 16px / 12px на мобилке.
- Кнопка «Оставить заявку» остаётся на нижней карточке.

## Заготовка в Тильде

В `#rec3354439901` нужны классы на группах-шапках: `warningcard-1` … `warningcard-4`. Описание — соседний текстовый элемент после группы. CTA — группа `data-group-id="1787822608320000002"`.

## Демо

`overlap-cards/demo.html` — локально через сервер.
