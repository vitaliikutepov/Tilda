# Стек карточек с нахлёстом

Блок из четырёх карточек: стоят стопкой, нижняя перекрывает край верхней. По ховеру карточка выдвигается вниз и показывает описание.

## Подключение

1. Зеро-блок: тёмный фон (`#050203` / чёрный).
2. Весь файл `overlap-cards/tilda-embed.html` вставить в HTML-элемент Тильды.
3. Ссылку кнопки «Оставить заявку» заменить на попап, например `href="#popup:form"`.
4. Тексты заголовков, описаний и подсказок (`?`) правятся прямо в разметке.

## Поведение

- Карточки с нахлёстом `--ocs-overlap` (по умолчанию 20px), нижние выше по `z-index`.
- Ховер / фокус: раскрывается дополнительный текст, карточки ниже чуть съезжают.
- На тач-экранах — тап; открыта одна карточка.
- Нижняя карточка всегда показывает блок «Не уверены…» и кнопку.

## Демо

`overlap-cards/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
