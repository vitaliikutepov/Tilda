# Warning-карточки (`#rec3354439901`)

Сниппет для зеро-блока на [h1bg-special](https://form.ptsecurity.com/h1bg-special). Вешается на уже свёрстанные группы `.warningcard-1` … `.warningcard-4`.

## Что вставлять

Только **`overlap-cards/tilda-embed.html`** — в HTML-элемент страницы или T123. Не `demo.html`.

В редакторе Тильда HTML не рисует — нужна публикация.

## Поведение

- Карточки **на местах и с высотами заготовки** Тильды: без своего зума, стека и `top`/`left`/`width`/`height`. Перекрывают друг друга как в макете.
- Стек слоёв **фиксированный**: `.warningcard-1` («Хищение…») сзади → `.warningcard-4` («Массовая…») спереди. Ховер и тап его не меняют. Карточки 1–3 на `z-index: 3` (как остальные элементы артборда Тильды), иначе 1–2 уходят под свечение и не кликаются.
- Доп. текст занимает своё место, но прозрачен: появляется **и пропадает** фейдом 0.8s.
- При открытии нижние карточки сдвигаются через `translateY` ровно на высоту доп. текста **+ 8px зазора** (считается по факту для каждой карточки).
- **≥1366px** — ховер. **&lt;1366px** — аккордеон по тапу.
- Стиль: фон `#FF0000` 10%, обводка 1px `#FF0000` 10%, blur 150px, радиус 16 / 12.
- Четвёртая карточка: высота заготовки (309), фейд заливки и обводки через `::before` с маской — **текст в маску не попадает**.
- Группа «Не уверены… / Оставить заявку» **не модифицируется**.

## Заготовка в Тильде

Нужны классы на группах: `warningcard-1` … `warningcard-4`. Описание — текстовый элемент внутри группы (или соседний после неё — тогда скрипт перенесёт его внутрь).
