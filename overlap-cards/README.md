# Стек карточек с нахлёстом

Блок из четырёх карточек: стоят стопкой, нижняя перекрывает край верхней. По ховеру карточка выдвигается вниз и показывает описание.

## Что вставлять в Тильду

Только файл **`overlap-cards/tilda-embed.html`**.

`demo.html` вставлять нельзя: это локальный превью, он подгружает сниппет через `fetch('tilda-embed.html')`. На сайте Тильды этого файла нет, поэтому карточки не появляются.

В редакторе Тильды HTML **не рисуется** — только после публикации.

## Куда вставить

**Вариант A — блок T123 (предпочтительно)**  
Библиотека блоков → Другое → «Вставка HTML-кода». Вставить содержимое `tilda-embed.html`. Высота подстроится сама.

**Вариант B — элемент HTML в зеро-блоке**  
1. Тёмный фон блока (`#000` / `#050203`).
2. Элемент HTML: ширина **100%**, высота **от 600px**, выравнивание **сверху**, контейнер **Grid** (не Window).
3. Вставить содержимое `tilda-embed.html`.
4. Опубликовать страницу.

Ссылку кнопки «Оставить заявку» заменить на попап, например `href="#popup:form"`. Тексты и подсказки (`?`) правятся в разметке.

## Поведение

- Карточки с нахлёстом `--ocs-overlap` (по умолчанию 20px).
- Ховер / фокус: раскрывается описание, карточки ниже чуть съезжают.
- На тач-экранах — тап; открыта одна карточка.
- Нижняя карточка всегда показывает блок «Не уверены…» и кнопку.

## Демо

`overlap-cards/demo.html` — только локально, через сервер (подгружает `tilda-embed.html`).
