# Warning-карточки (`#rec3354439901`)

Сниппет для зеро-блока на [h1bg-special](https://form.ptsecurity.com/h1bg-special). Вешается на уже свёрстанные группы `.warningcard-1` … `.warningcard-4`.

## Что вставлять

Только **`overlap-cards/tilda-embed.html`** — в HTML-элемент страницы или T123. Не `demo.html`.

В редакторе Тильда HTML не рисует — нужна публикация.

## Поведение

- Карточки **остаются на местах заготовки** Тильды: без своего зума, стека и `top`/`left`/`width`.
- По умолчанию закрыты (видна шапка). Описание прячется, карточки ниже сдвигаются через `translateY`.
- **≥1366px** — ховер. **&lt;1366px** — аккордеон по тапу.
- Стиль: фон `#FF0000` 10%, обводка 1px `#FF0000` 10%, blur 150px, радиус 16 / 12.
- Четвёртая карточка с фейдом заливки и обводки (`mask`) в открытом виде.
- Группа «Не уверены… / Оставить заявку» **не модифицируется**.

## Заготовка в Тильде

Нужны классы на группах-шапках: `warningcard-1` … `warningcard-4`. Описание — соседний текстовый элемент после группы.

## Демо

`overlap-cards/demo.html` — локально через сервер.
