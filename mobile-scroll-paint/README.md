# Мобильная отрисовка без пустого кадра

Сниппет для страницы [h1bg-special](https://form.ptsecurity.com/h1bg-special).

На телефоне при быстром скролле сначала виден тёмно-серый фон, потом блок или отдельные элементы резко появляются. Это не сеть и не «тяжёлые картинки» в первую очередь — контент уже в DOM, но Тильда держит его невидимым до попадания во вьюпорт.

## Почему так

1. **Appear-анимации Zero Block** (`fadein` / `fadeinup`, в том числе с галкой «анимация на мобильных»). CSS Тильды:

   ```css
   .t396 .t-animate[data-animate-style=fadein],
   .t396 .t-animate[data-animate-style=fadeinup] { opacity: 0 }
   ```

   JS добавляет `t-animate_started` только когда элемент в кадре. Observer ещё и с отрицательным `rootMargin` (~20% высоты блока), старт системы анимаций — через **1.5 с** после init.

2. **SBS «при появлении»** (`data-animate-sbs-event="intoview"` + класс `t396__elem--anim-hidden`). Группа скрыта, пока не сработает шаг анимации. На герое есть fade 0→1 на 5–10 с.

3. **Фон, который видно «пустым».** `body` в `custom.css` — `#1B1B1B`. Карточки в зеро-блоках — `#1a1b23` / `#272831`. Оболочка красится сразу, текст и внутренности сидят с `opacity: 0`.

4. **Тяжёлая отрисовка.** ~2200 `tn-elem`, `backdrop-filter: blur(150px)` на warning-карточках. На мобилке GPU откладывает слои: при быстром скролле кадр успевает показать фон, контент дорисовывается позже.

На странице это уже частично обходили точечно (`#rec3351087301 .t-animate { opacity: 1 }` в текстовом слайдере). Сниппет делает то же для всей страницы.

## Подключение

1. Весь файл `tilda-embed.html` вставить в HTML-элемент Тильды (настройки страницы или T123).
2. Опубликовать страницу.

## Что ещё стоит выключить в редакторе

Сниппет закрывает симптом. Чтобы не воевать с Тильдой и разгрузить GPU:

- У элементов Zero Block снять **«Анимация на мобильных»** (сейчас `data-animate-mobile="y"` у ~18 элементов, включая заголовки секций).
- Убрать appear `fadeinup` у заголовков секций — они как раз «всплывают» после пустого фона.
- На герое не держать fadein с длительностью **10 с** и SBS fade **5 с**.
- На карточках рисков заменить `blur(150px)` на непрозрачный фон или `blur(12px)`.
- По возможности упростить самые тяжёлые зеро-блоки (`#rec3351087601` ~437 элементов, `#rec3354674601` ~368).

## Демо

`demo.html` — открывать через локальный сервер.

- По умолчанию сниппет включён: карточки сразу с текстом.
- `demo.html?nofix=1` — как Тильда: пустой серый блок, контент появляется только в кадре.
