# Тултипы иконок меню (Windows)

Сниппет для шапки [pt-sandbox-email-security-minsk](https://form.ptsecurity.com/pt-sandbox-email-security-minsk): подписи у иконок («Перейти на сайт Positive Technologies», «Перейти на страницу продукта») должны появляться по hover, а не висеть сразу.

## Почему баг на Windows

В зеро-блоке `#rec2488841961` три группы-тултипа с пошаговой анимацией Тильды:

| Тултип | Текст | Триггер (иконка) |
| --- | --- | --- |
| `1775645713850000002` | Перейти на сайт Positive Technologies | `1775551052249000004` → ptsecurity.com |
| `1775645959303000001` | Перейти на страницу продукта | `1775551037645` → PT Sandbox |
| `1784636522816000004` | Перейти на страницу продукта | `1784636183728000001` → PT Email Security |

Тильда прячет их так:

```css
@media (min-width: 1200px) {
  .tn-group.t396__elem--anim-hidden[data-group-id="…"] { opacity: 0; }
}
```

А `tilda-animation-sbs` **выключает** hover-анимацию, если артборд-брейкпоинт `< 1200`: снимает `t396__elem--anim-hidden` и оставляет группу в исходном состоянии (opacity 1).

Сетка блока: `320, 768, 1024, 1366, 1920`. На ширине **1024–1365 CSS-пикселей** Тильда берёт res = `1024` и считает, что hover нет. Как раз туда попадают Windows-машины:

- 1920×1080 при масштабе 150% → ~1280px (между брейкпоинтами 1024 и 1366);
- 1920×1080 при 125% в окне браузера (не на весь экран);
- 1366×768, если окно чуть уже из‑за панелей.

На macOS CSS-ширина обычно ≥ 1366 (Retina не сжимает layout, как Windows DPI), поэтому там hover Тильды отрабатывает.

## Подключение

Весь файл `tilda-embed.html` вставить в HTML-элемент Тильды **в шапке страницы** (T123 или HTML в настройках страницы), лучше выше зеро-блока с иконками — тогда CSS спрячет тултипы до первой отрисовки.

Сниппет не завязан на конкретные id: берёт любые группы с `data-animate-sbs-event="hover"` и `data-animate-sbs-trgels`.

## Поведение

- Тултипы скрыты (`opacity: 0`), пока курсор или фокус не на соответствующей иконке.
- На узких экранах, где Тильда и так уводит группы за край (`left: -380px`), они остаются скрытыми — это нормально, hover на таче не нужен.

## Демо

`demo.html` — открыть в браузере. Слева имитация бага Тильды, справа тот же блок со сниппетом.
