# Текстовый слайдер для Tilda Zero Block

Слайдер с автопроигрыванием и пагинацией «прогрессбар + точки» для страницы [h1bg-special](https://form.ptsecurity.com/h1bg-special) (зеро-блок `#rec3351087301`).

## Подключение

1. В зеро-блоке UI:
   - стрелки `.main-slider-left` / `.main-slider-right`;
   - текстовый элемент `.slider-text-2`;
   - пагинация: группы `.cslide4-1` … `.cslide4-4` и шейпы `.slide4-1` … `.slide4-4`.
     Активный пункт в макете — полоска 24×4, остальные — точки 4×4.
2. Весь файл `text-slider/tilda-embed.html` вставить в HTML-элемент Тильды.
3. Тексты слайдов — массив `SLIDE_TEXTS` внутри сниппета:
   1. Без рисков и остановки реальных бизнес-процессов
   2. Бесплатно для участников сообщества
   3. 2 недели испытаний
   4. Оплата исследователям за счет Positive Technologies

## Поведение

- Текст меняется в три фазы (как main-slider): фейд-аут 0.5с → ширина едет 0.5с, стрелки скользят → фейд-ин 0.5с.
- Ширина текста hug, с потолком по вьюпорту: &lt;768 — 280px, 768–1024 — 616px, 1024–1366 — 1002px, 1366+ — 864px. Если строка длиннее — перенос. На телефоне hug отключён: текст всегда переносится внутри 100% родителя (макс. 280px), без nowrap.
- Автосмена каждые 5 секунд; прогресс плавно заполняет активный пункт (серый трек `#676767`, белая заливка через `scaleX`). Активный пункт сразу 24px, без промежуточного «наливания» точки.
- Активный пункт пагинации — прогрессбар, остальные — белые точки.
- Клик по стрелке / точке или свайп сбрасывает таймер.
- Наведение на блок ставит автоплей на паузу.

## Демо

`text-slider/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
