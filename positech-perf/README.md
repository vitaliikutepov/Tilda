## Почему медленно

1. **Один документ на 4 МБ.** ~96 зеро-блоков, у каждого свой огромный `<style>` на 5 брейкпоинтов. Около половины — пустые спейсеры высотой 44–120 px; пустой Zero всё равно отдаёт десятки КБ CSS. Пока HTML парсится, страница пустая.
2. **Тильда прячет контент на первом визите.** Скрипт в `<head>` ставит `.t-records { opacity: 0 }` (desktop ≥980px) и снимает его только после `DOMContentLoaded` + 400 мс. Вместе с пунктом 1 это выглядит как «сайт долго грузится».
3. **Два mp4 стартуют сразу.**
   - Annexx (`#rec2459752113`): `play-onload-page: true`, `play-video-unmute-load: true`, файл с `dl.dropboxusercontent.com`.
   - Zero-видео (`#rec2459752133`): `data-field-autoplay-value="y"` + loop, `globe.mp4` 3.9 МБ — декоративный глобус рядом со статистикой 90/33/60%.
4. **Один и тот же виджет карусели вставлен 8 раз**, и каждый тащит свои копии:
   - `jquery-1.12.4.min.js` (Тильда уже грузит `jquery-1.10.2`)
   - `owl.carousel.min.css` + `owl.carousel.min.js`
   - `animate.css`  
   Блоки: `#rec2459752203`, `#rec2459752313`, `#rec2459752383`, `#rec2459752473`, `#rec2459752643`, `#rec2459752763`, `#rec2459752873`, `#rec2459752903`.
5. **GTM подключен дважды:** кастомный HTML `GTM-WCJGMLVL` в head и встроенная аналитика Тильды `G-7H4TX4C47N` + тот же GTM.
6. **Тяжёлые PNG** без WebP: `Frame_2147239051.png` 651 КБ, `video_player_6.png` 265 КБ, `Group_2087330856_1.png` 201 КБ, `enhanced_image_23949.png` 183 КБ. Четыре картинки грузятся eager, без `data-original`.

## Что делает сниппет

Файл `tilda-embed.html` — вставлять в **Настройки страницы → Дополнительно → HTML-код в HEAD** (как можно выше).

- сразу показывает `.t-records`;
- **один jQuery на страницу:** Тильда грузит 1.10.2, виджеты слайдеров — ещё 8× 1.12.4. Повторная загрузка **затирает `$` и снимает `$.fn.owlCarousel`**, из‑за этого слайдеры как раз и ломаются. Сниппет замораживает первый `window.jQuery` / `$` и глушит следующие теги `jquery-*.js`, `owl.carousel`, `animate.css`;
- **один GTM-контейнер:** второй `gtm.js?id=GTM-…` с тем же id не вставляется. Два одинаковых контейнера дают двойные события, не «запасной» трекинг;
- не качает Dropbox/globe mp4, пока ролик не в кадре;
- `loading=lazy` для картинок ниже первого экрана.

Ограничения:

- Статичные `<script src>` в HTML браузер может всё равно **скачать** (preload scanner). Повторный URL обычно берётся из кэша; вред был в **повторном execute**, который мы отсекаем.
- GTM ловится надёжно: он создаётся через `document.createElement`, не парсером.
- `gtag.js` Тильды (`G-7H4TX4C47N`) сниппет не трогает. Если GA4 уже идёт из GTM, галку аналитики Тильды лучше выключить в настройках сайта — иначе будут двойные просмотры.
- HTML на 4 МБ сниппет не уменьшит.

Если вставлять T123-блоком, а не в HEAD, дедуп jQuery опоздает: часть тегов уже исполнятся. HEAD обязателен.

## Правки в Тильде (по эффекту)

### 1. Уменьшить HTML — главный рычаг

- Склеить соседние Zero в один артборд. Цель: сильно меньше 96 Zero.
- Пустые спейсеры 44/60/72/120 px заменить паддингом соседнего блока и удалить.
- Сайт → Настройки → Анимация → выключить плавное появление сайта (тот самый `opacity: 0`).

### 2. Видео

Annexx `#rec2459752113`:

- залить mp4 в Тильду, убрать Dropbox;
- сжать до ~1 МБ (720p, H.264);
- выключить play on page load и unmute on load;
- включить play when visible on screen;
- `preload=none`, постер уже есть (`enhanced__2_1_1.jpg`).

Глобус `#rec2459752133`:

- выключить autoplay или заменить на статичный SVG (`Typeglobe.svg` уже на странице);
- если ролик нужен — только когда блок в кадре, без loop на мобиле.

### 3. Карусели Nolim / Owl

В семи из восьми HTML-блоков удалить строки:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/owl.carousel@2.3.4/dist/assets/owl.carousel.min.css">
<link href="https://cdn.jsdelivr.net/npm/animate.css@4.1.1/animate.min.css" rel="stylesheet">
<script src="https://code.jquery.com/jquery-1.12.4.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/owl.carousel@2.3.4/dist/owl.carousel.min.js"></script>
```

Оставить библиотеки в **одном** блоке. jQuery Тильды (`jquery-1.10.2`) для Owl 2.3 обычно достаточно — отдельный 1.12.4 не нужен.

### 4. Аналитика и картинки

- Оставить либо GTM в кастомном HTML, либо галку Тильды, не оба (сниппет глушит второй `gtm.js` с тем же id, но `gtag.js` Тильды не трогает).
- Перезалить крупные PNG как WebP (в Тильде: оптимизация изображений / WebP).
- `Frame_2147239051.png` (651 КБ) — кандидат №1.

После правок: опубликовать страницу и прогнать [PageSpeed Insights](https://pagespeed.web.dev/analysis?url=https://positech.id/).
