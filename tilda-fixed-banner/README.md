# Фиксированный баннер для Tilda Zero Block

Стики-баннер для страницы [project14053621](https://project14053621.tilda.ws/) (зеро-блок `#rec2643778101`).

## Подключение

Весь файл `tilda-fixed-banner/tilda-embed.html` вставить в «Настройки страницы → Дополнительно → HTML-код для вставки внутрь BODY» (или блок T123).

В зеро-блоке должны быть классы:

- `banner-image`, `banner-header`, `banner-text`, `banner-button`
- `close-banner` — крестик / иконка раскрытия на мобилке

## Поведение

- Блок закреплён внизу экрана, выезжает после 1600px прокрутки, прячется у конца страницы.
- `.close-banner` закрывает баннер.
- До 768px баннер стартует свёрнутым (видны картинка, заголовок и иконка).
- **Тап по всей карточке** разворачивает баннер. После этого:
  - «Подробнее» (`.banner-button`) работает как ссылка;
  - крестик закрывает баннер.

## Демо

`tilda-fixed-banner/demo.html` — открывать через локальный сервер.
