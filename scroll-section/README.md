# Анимация `.scroll-section`

Скролл-анимация для зеро-блока Тильды: блок с картинкой сначала на всю ширину окна браузера, при доскролле до секции сужается к размерам из редактора.

Работает **только от 1024px**. На планшетах и телефонах остаются исходные размеры Тильды.

## Подключение

1. В зеро-блоке повесьте CSS-класс `scroll-section` на элемент с изображением:
   - фигуру с фоновой картинкой, или
   - элемент-изображение, или
   - группу, если фон задан на самой группе.
2. Вставьте `tilda-embed.html` в HTML-элемент Тильды (или в HTML-код страницы).

Класс лучше вешать именно на картинку, а не на группу с текстом поверх: анимируется ширина и `left` этого узла.

## Поведение

На вьюпортах ≥ 1024px:

- пока секция ещё ниже экрана — ширина равна ширине окна, скругление 0;
- по мере появления в вьюпорте ширина, `left` и `border-radius` интерполируются к значениям из Тильды;
- когда верх блока оказывается примерно на 22% высоты окна — исходный размер;
- при скролле обратно секция снова растягивается.

`prefers-reduced-motion: reduce` отключает анимацию.

## Демо

`scroll-section/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
