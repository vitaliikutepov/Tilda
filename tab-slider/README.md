# Таб-слайдер для Tilda Zero Block

Слайдер с табами для страницы [parent-new](https://project14053621.tilda.ws/parent-new).

## Подключение

1. В зеро-блоке UI:
   - группа с классом `tab-container` — сюда подставляются слайды;
   - стрелки `.tab-prev` / `.tab-next`;
   - кнопки `.tab1` … `.tab6`.
2. Контент слайдов — отдельные зеро-блоки (скрываются скриптом):
   - tab1 — `#rec3057670801`
   - tab2 — `#rec3057679701`
   - tab3–tab6 пока чередуют эти же два блока (меняется в `TAB_SOURCES` внутри `tilda-embed.html`).
3. Весь файл `tab-slider/tilda-embed.html` вставить в HTML-элемент Тильды.

## Поведение

- Слайды меняются кроссфейдом внутри `.tab-container`.
- Активный таб: фон `#8742EE`, прогресс слева направо `#9F68F1`.
- Автосмена каждые 6 секунд; клик по табу, стрелке или свайп сбрасывает таймер.
- На телефоне свайп по слайду: влево — следующий, вправо — предыдущий.
- На вьюпортах до 1366px ряд табов скроллится пальцем, активная кнопка всегда доскролливается в видимую область.

## Демо

`tab-slider/demo.html` — открывать через локальный сервер (подгружает `tilda-embed.html`).
